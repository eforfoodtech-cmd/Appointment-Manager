Saat input validation ve default çalışma saatlerini düzelt.

İlgili alanlar:

artifacts/mobile/app/(barber)/profile.tsx
artifacts/mobile/app/(barber)/slots.tsx
artifacts/api-server/src/routes/barbers.ts

Sorunlar:

Backend fallback seed-week 10:00–23:00 arası 13 slot üretiyor.
Frontend DEFAULT_TEMPLATE 10:00–22:00 kullanıyor. Bu kullanıcıda 13 slotun 12’ye düşmesi gibi kafa karışıklığı yaratıyor.
Saat inputları serbest TextInput. Kullanıcı abc, 25:99, 9 gibi bozuk değerler girebilir.

İstenen düzeltmeler:

A) Frontend default programı backend fallback ile eşitle:

DEFAULT_TEMPLATE içinde endTime "22:00" yerine "23:00" olsun.
Placeholder/yardım metinleri gerekiyorsa 23:00 ile uyumlu olsun.

B) Berber çalışma saatlerini kendi ayarlayabilmeli:

Sabah 07:00 gibi erken saatler geçerli olmalı.
Akşam/gece kapanış için 24:00 geçerli olmalı.
24:00 sadece endTime/kapanış saati olarak kabul edilsin.
startTime için 24:00 kabul edilmesin.
Gece aşan program şimdilik desteklenmesin. Örneğin 22:00–02:00 hata versin.

C) Frontend validation ekle:

startTime formatı HH olsun.
startTime 00:00–23:59 arası olsun.
endTime formatı HH olsun.
endTime 00:01–24:00 arası olsun.
startTime < endTime kontrol edilsin.
slotDuration sadece 30, 45, 60, 90 olabilir.
Program kaydetmeden önce validation fail olursa kullanıcıya toast/alert ile anlaşılır Türkçe hata gösterilsin.
Manuel slot eklemede de aynı HH ve start < end kontrolü yapılsın.
Manuel slot ekleme için endTime 24:00 kabul edilebilir ama startTime 24:00 kabul edilmesin.

D) Backend validation da eklensin:

POST /api/barbers/me/slots için date, startTime, endTime format kontrolü.
PATCH /api/barbers/me/slots/ için isAvailable boolean kontrolü.
PUT /api/barbers/me/availability için her row:
dayOfWeek 0–6
isOpen boolean
startTime valid HH
endTime valid HH
startTime < endTime
startTime 00:00–23:59
endTime 00:01–24:00
24:00 sadece endTime için geçerli
slotDuration 30/45/60/90
Hatalı inputlarda 400 Bad Request ve anlaşılır Türkçe hata dönsün.

E) Typecheck temiz olmalı:
cd ~/workspace
pnpm run typecheck
