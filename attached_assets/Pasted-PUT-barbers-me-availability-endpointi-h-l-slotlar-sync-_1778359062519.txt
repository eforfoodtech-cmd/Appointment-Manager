PUT /barbers/me/availability endpointi hâlâ slotları sync etmiyor. Direkt public API ile test ettik:

1. PUT /api/barbers/me/availability 200 OK döndü.
2. availability tablosunda day_of_week=2 için is_open=false oldu.
3. Ama appointment_slots içinde 2026-05-12 Salı slotları hâlâ duruyor:
   10:00–10:45, 10:45–11:30, 11:30–12:15...
   Bu yanlış. Salı kapalıysa aktif randevusu olmayan Salı slotları silinmeli veya müşteri tarafında görünmeyecek şekilde kapatılmalı.

Kök sorun:
PUT availability endpointinde syncDaySlots ya hiç çalışmıyor, ya yanlış barberId/date buluyor, ya da eski code path public API’de çalışıyor.

Dosya:
artifacts/api-server/src/routes/barbers.ts

İstenen kesin çözüm:

1. PUT /barbers/me/availability içinde availability kayıtları DB’ye yazıldıktan sonra, request body’deki her row için rolling week’te karşılık gelen date bulunmalı ve syncDaySlots çağrılmalı.

2. Day/date mapping kesin doğru olmalı:
   JS getDay mantığı:
   0 = Pazar
   1 = Pazartesi
   2 = Salı
   3 = Çarşamba
   4 = Perşembe
   5 = Cuma
   6 = Cumartesi

3. Örnek:
   Eğer request body’de dayOfWeek=2 gelirse ve rolling week içinde 2026-05-12 Salı varsa, syncDaySlots(barberId, "2026-05-12", salıAvailabilityRow) çalışmalı.

4. syncDaySlots davranışı:

   * Eğer availability.isOpen=false ise:

     * O date/barberId için aktif appointment olmayan slotları kaldır.
     * Aktif appointment bağlı slotları koru.
     * Aktif appointment tanımı: status NOT IN ('cancelled','no_show')
   * Eğer availability.isOpen=true ise:

     * Aktif appointment bağlı slotları koru.
     * Aktif appointment olmayan eski slotları temizle.
     * availability.startTime/endTime/slotDuration’a göre slotları sıfırdan üret.
     * start + slotDuration <= endTime olmalı.
     * 30/45/60/90 dk desteklenmeli.
     * Eski yanlış slotlar kalmamalı.

5. Önemli:
   Sadece seed-week route’unu düzeltmek yetmez.
   PUT /availability kendi başına DB’yi tutarlı hale getirmeli.

6. Public API testini bizzat çalıştır:

   * Berber login ile token al.
   * PUT /api/barbers/me/availability ile Salı dayOfWeek=2 isOpen=false gönder.
   * Sonra DB’de:
     SELECT * FROM availability WHERE barber_id=2 ORDER BY day_of_week;
     SELECT id,date,start_time,end_time,is_available,is_booked FROM appointment_slots WHERE barber_id=2 AND date='2026-05-12' ORDER BY start_time;

7. Başarı kriteri:

   * availability day_of_week=2 is_open=false olmalı.
   * 2026-05-12 için aktif randevusu olmayan slotlar artık müşteri tarafında görünmemeli.
   * Eğer aktif randevu yoksa 2026-05-12 slot listesi boş olmalı.

8. Sonra Salı’yı tekrar açık 30 dk yap:
   dayOfWeek=2, isOpen=true, startTime=10:00, endTime=23:00, slotDuration=30

   Başarı kriteri:
   2026-05-12 slotları:
   10:00–10:30
   10:30–11:00
   11:00–11:30
   ...
   Eski 10:00–10:45 gibi 45 dk slotlar kalmamalı.
